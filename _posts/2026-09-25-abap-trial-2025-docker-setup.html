기존 환경(2023) 정리

  • 디스크 용량 확보와 충돌 방지를 위해 2023 컨테이너와 이미지를 완전히 삭제

3

Docker Desktop / WSL2 트러블슈팅

  • Docker Desktop 최신 버전으로 업데이트한 뒤 "WSL needs updating" 오류 발생
  • 원인은 WSL 자체가 시스템에 설치되어 있지 않았던 상태

해결 절차

  1. 관리자 권한 PowerShell에서 Windows 기능 활성화
  2. 재부팅 후 WSL 업데이트 최종 확인된 버전: WSL 2.7.14.0, 커널 6.18.33.2
  3. Docker Desktop 재실행 후 정상 기동 확인 (docker version, docker ps -a 정상 응답)

  • 경로: C:\Users\holim-home\.wslconfig

라이선스 등록

  • 이미지에 포함된 AS ABAP 라이선스는 3개월 유효
  • 최초 로그인 시 별도 등록 절차가 필요

1. 기본 계정 정보

UserClientPassword
SAP*000ABAPtr2025#SP00
DDIC000 / 001
DEVELOPER001 (최초엔 잠김)

2. 등록 절차

  1. SAP*, client 000으로 최초 로그인
  2. SLICENSE 트랜잭션에서 Hardware Key 복사 (예: B1401380189)
  3. SAP minisap 라이선스 발급 페이지에서 시스템 A4H 선택, Hardware Key 입력 후 라이선스 파일 발급
  4. SLICENSE 화면에서 Install을 눌러 발급받은 파일 적용
  5. 로그아웃 후 DEVELOPER, client 001로 재로그인
  6. SLICENSE에서 기존 무효(inactive hardware key) 라이선스 삭제 — SAP*는 삭제 권한이 없어 DEVELOPER로 처리
라이선스 만료일: 2026-12-25
만료 전(권장: 12월 20일 전후) 위 2~4번 절차를 동일하게 반복해서 갱신해야 합니다. 미갱신 시 AS ABAP 로그인이 차단됩니다.

같은 네트워크 내 원격 접속 구성

  • 미니PC(서버, 유선)와 노트북(클라이언트, Wi-Fi)이 같은 공유기(같은 서브넷)에 연결되어 있어 유/무선 차이와 무관하게 동일한 방식으로 구성 가능
  • 순서: 서버 IP 확인, 방화벽 허용, 클라이언트 hosts 등록, SAP GUI 연결

1. 서버 IP 확인

vEthernet (Default Switch), vEthernet (WSL) 등 가상 어댑터의 IP(예: 172.19.x.x, 172.31.x.x)는 호스트 내부용이므로 외부 접속 주소로 쓰면 안 됩니다. 실제 이더넷 어댑터의 IP만 사용하세요.

2. 트러블슈팅 — Ping 응답 없음

원인은 네트워크 프로필이 Public으로 설정되어 인바운드 연결이 차단된 것이었습니다. 그룹 정책으로 Private 전환이 막혀 있어, 대신 방화벽 룰에 -Profile Any를 지정해 우회했습니다.
